# exdreamcolors - Free Online Color Tools

Free color tools for developers and designers. Color picker, palette generator, gradient maker, contrast checker, and more.

## Tools

- **Color Picker** - Pick any color and get HEX, RGB, HSL values
- **Palette Generator** - Generate color schemes based on color theory
- **Image Color Extractor** - Extract colors from any image
- **Gradient Generator** - Create beautiful CSS gradients
- **Contrast Checker** - Check WCAG accessibility compliance
- **Tailwind Generator** - Generate Tailwind CSS color configurations

## Tech Stack

- Next.js 14
- React 18
- Tailwind CSS
- TypeScript

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

## Deploy

Deploy to Cloudflare Pages for free hosting.
